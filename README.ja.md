# Neovim 向け JsonCrack プレビュー

[English](README.md)

保存済みの JSON または YAML ファイルを、既定のブラウザーで JSON Crack
公式のグラフ表示として開きます。ファイルを保存するとグラフも自動で更新
されます。プレビューサーバーとブラウザー用アセットはローカルで動作します。

このプラグインは非公式の Neovim 連携機能であり、JSON Crack とは提携・承認
関係にありません。

## 主な機能

- 保存済みの `.json`、`.yaml`、`.yml` ファイルをプレビュー
- ファイルの保存後にグラフを自動更新
- 同梱アセットと小さな Python サーバーでローカル実行

## 必要環境

- Neovim 0.11 以降
- `python3` として実行できる Python 3.10 以降
- 既定のブラウザーと動作する `vim.ui.open` を備えた Linux デスクトップ環境
- LazyVim と `lazy.nvim`、または `plugin/jsoncrack.lua` を読み込む設定

プラグインの実行に Node.js、npm、pip、ネットワーク接続、インストール時の
ビルドは必要ありません。

## インストール

[GitHub](https://github.com/TRJ89/jsoncrack-nvim) からインストールします。
LazyVim では、次の内容を `~/.config/nvim/lua/plugins/jsoncrack.lua` に保存
します。

```lua
return {
  {
    "TRJ89/jsoncrack-nvim",
    cmd = {
      "JsonCrackPreviewToggle",
      "JsonCrackPreviewOpen",
      "JsonCrackPreviewStop",
    },
    keys = {
      {
        "<leader>cj",
        "<cmd>JsonCrackPreviewToggle<cr>",
        desc = "JSON Crack プレビューを切り替え",
      },
    },
  },
}
```

コントリビューター向けのローカルチェックアウトについては
[開発ガイド](docs/development.md) を参照してください。

`<leader>cj` の割り当ては任意です。環境に合わせて変更または削除できます。
`setup()` の呼び出しやビルドフックはありません。

## 使い方

保存済みの JSON または YAML ファイルを開き、設定したキーまたは次のコマンド
を実行します。

- `:JsonCrackPreviewToggle` 現在のバッファでプレビューを開始します。すでに
  プレビュー中なら、対象バッファにかかわらずそのセッションを停止します。
- `:JsonCrackPreviewOpen` プレビューがなければ開始します。同じファイルが
  プレビュー中なら現在の URL を既定のブラウザーで再度開きます。別のファイル
  が対象なら、先にそのプレビューを停止してください。既存のタブを再利用する
  とは限らず、新しいタブが開く場合があります。
- `:JsonCrackPreviewStop` サーバーを停止します。開いているブラウザータブは
  残り、再接続できないことを表示します。

プレビューにはディスクに保存した内容が使われます。編集後は `:write` で保存
してください。ブラウザーは 500 ms ごとに保存内容を確認し、手動で再読み込み
しなくても表示を更新します。保存されていない編集はプレビューに含まれません。
対象バッファがどのウィンドウにも表示されなくなったとき、アンロード・破棄・
名前変更されたとき、または Neovim の終了時にサーバーは停止します。ブラウザー
タブを閉じただけでは停止しません。ページを再表示するには
`:JsonCrackPreviewOpen` を実行してください。

グラフのノードをクリックすると、完全な内容と JSON Path をダイアログで表示
します。プリミティブ値と配列ノードには実際の JSON 値が表示されます。オブジェクト
ノードには直下のプリミティブ値と空のコンテナーが表示され、空でない子コンテナーは
別のノードで確認できます。内容とパスは個別にコピーできます。閉じるボタン、Escape、
または背景のクリックでダイアログを閉じます。空の `{}` と `[]` には **View details**
アクションがあります。有効な保存内容に更新するとダイアログは閉じます。無効な保存内容
では最後に有効だったグラフと開いている詳細が保持されます。

ダイアログは画面に合わせて広がります。長い JSON は折り返さずに表示し、縦横に
スクロールできます。テキストは選択できます。

## 制限

対応するのは保存済みの読み取り可能な通常ファイル `.json`、`.yaml`、`.yml`
だけです。JSONC やその他の形式には対応しません。入力サイズ、ネスト、グラフ
ノード数には上限があり、未対応の構文は一部だけを表示せずエラーになります。
[入力仕様](docs/input-support.md)に全ルールを、[検証記録](docs/validation.md#performance-method-and-results)
に性能測定と条件を記載しています。

現時点の対応環境は Linux デスクトップです。ヘッドレス Neovim、SSH セッション、
1 つの Neovim プロセス内での複数プレビュー、名前変更後のバッファ追従、ブラウザー
タブを閉じたときの自動停止には対応していません。

## トラブルシューティングとサポート

- **保存を求められる:** 名前のある `.json`、`.yaml`、`.yml` ファイルとして
  保存してください。プレビューにはディスク上の内容が使われます。
- **構文または上限のエラーが表示される:** [入力仕様](docs/input-support.md)
  を確認し、必要に応じてサイズ、ネスト、グラフノード数を減らしてください。
  次の有効な保存内容が表示されます。
- **Python またはブラウザーアセットが見つからない:** `python3 --version` を
  確認し、プラグインが `server/` と `dist/` を含むチェックアウトを指している
  ことを確認してください。
- **ブラウザーが開かない:** 既定のブラウザーを設定した Linux デスクトップで
  利用し、Neovim の `vim.ui.open` が動作することを確認してください。リモート
  とヘッドレス環境には対応していません。
- **古いタブが再接続できない:** Neovim からプレビューを開始または再表示して
  ください。

問題の報告や別環境への対応リクエストには
[Issue トラッカー](https://github.com/TRJ89/jsoncrack-nvim/issues) を利用できます。
OS、Neovim のバージョンと設定、利用目的を添えてください。他の環境への対応は
検討しますが、対応を約束するものではありません。
