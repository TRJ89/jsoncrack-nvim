# Security Policy

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/TRJ89/jsoncrack-nvim/security/advisories/new) when it is available. This repository must have private vulnerability reporting enabled for the form to accept a private report; adding this file does not enable that GitHub setting. See [GitHub's reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

If the form is unavailable, open a public issue only to ask maintainers for a private reporting channel. Do not include vulnerability details, affected components, reproduction steps, exploit code, or other sensitive information in a public issue or discussion.

There is no guaranteed response time. Please keep any report private while maintainers assess it and coordinate a fix.
